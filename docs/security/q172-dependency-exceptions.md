# q-172 dependency advisory exceptions

Owner: Murphy's Law. Review by **2026-12-15**. The Security workflow fails after that date until the exceptions are removed or a reviewer approves a new date with fresh evidence. This is the `herd/0.5.28` base's root `Cargo.lock`; the desktop Tauri workspace has a separate lockfile and is outside this inventory.

The q-171 baseline found 44 `cargo-deny` error blocks in 18 crate/version pairs. Compatible lockfile updates remove 34 blocks. Ten advisory IDs remain as individually documented exceptions in `deny.toml`:

| ID | Blocked upgrade and current exposure | Exit condition |
| --- | --- | --- |
| [0459](https://rustsec.org/advisories/RUSTSEC-2026-0459) | MeshLLM 0.76.2 pins `rusqlite 0.40` / `libsqlite3-sys 0.38`. Its log store opens a local SQLite database. The advisory requires a crafted database and sibling WAL file with mismatched page size; this remains a local file integrity concern. | Move MeshLLM and Buzz to `rusqlite 0.41` / `libsqlite3-sys >=0.39`, then remove the exception. |
| [0462](https://rustsec.org/advisories/RUSTSEC-2026-0462) | `buzz-agent` uses `rmcp 1.8` with `client` and `transport-child-process`. The affected Streamable HTTP client features are disabled. The 3.x API needs a separate migration. | Migrate `buzz-agent` to `rmcp >=3.9`, then remove the exception. |
| [0449](https://rustsec.org/advisories/RUSTSEC-2024-0449) | `serde_yaml 0.9` pulls the unmaintained `unsafe-libyaml`; there is no maintained version in this dependency line. This is an unmaintained warning, not a reported exploit. | Migrate all workspace YAML parsers to a maintained library and remove the exception. |
| [0371](https://rustsec.org/advisories/RUSTSEC-2026-0371), [0370](https://rustsec.org/advisories/RUSTSEC-2026-0370), [0372](https://rustsec.org/advisories/RUSTSEC-2026-0372) | MeshLLM's keyring path pulls `secret-service 5` and `zbus 5`, which depend on the three unmaintained crates. These advisories report no exploit. | Move the keyring stack to `zbus 6`, where these types are integrated, then remove all three exceptions. |
| [0367](https://rustsec.org/advisories/RUSTSEC-2026-0367), [0368](https://rustsec.org/advisories/RUSTSEC-2026-0368), [0369](https://rustsec.org/advisories/RUSTSEC-2026-0369), [0429](https://rustsec.org/advisories/RUSTSEC-2026-0429) | MeshLLM 0.76.2 pins `zip 8.6`. They do not call `ZipArchive::extract` or `ZipStreamReader::extract`, create symlinks, or restore archive permissions. Those are the affected APIs in these four advisories. | Move MeshLLM to `zip >=9` and remove all four exceptions. Review any new extractor API use before that migration. |
